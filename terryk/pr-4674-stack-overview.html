Background. Refit is the weight copy after each step. TransferQueue (TQ) holds rollout tokens until the trainer reads them. Gym runs the agents and talks to the model through an OpenAI-style HTTP API. Dotted words have a short explanation: hover or tap them.

The figure shows the finished stack. Each arrow is colored by the PR that adds it. #4674 adds the plain path: Gym sends chat requests to the server, and the trainer pushes new weights over NCCL, with HTTP for the control calls. #4675 loads a small wheel into the server that keeps the exact earlier tokens in multi-turn prompts. #4676 lets that wheel send each rollout's tokens to the controller, which writes them to TQ. #4677 is docs and an example config.

What #4674 itself adds

  • A new generation backend that launches nothing. It holds one HTTP client for one base_url and hands the same URL to Gym (remote_vllm_generation.py).
  • Startup checks: model name, vLLM version 0.29.0, NCCL transfer backend, GPU count, and exactly one backend (preflight.py).
  • Refit over NCCL with no checkpoint files. The trainer and server GPUs join one group, and HTTP carries the control calls (synchronizer). How this compares with managed vLLM: refit page.
  • Clear errors for colocated mode, ModelOpt, draft weights, token capture (until #4676), fleet health, and non-null refit_transport.
Design changes worth asking for (review, not yet posted). Details are on the linked pages.
  1. Add a seam for more than one server. Make the config "one rollout URL + a list of admin URLs", with a small refit interface behind it. That opens up several replicas, an externally launched Dynamo, and later a colocated IPC version (colocated & Dynamo).
  2. Wait for the server. Preflight runs once with a 5 s timeout, so a Slurm job that starts both sides together dies. Then reuse main's two-group launcher (Slurm launch).
  3. Refuse what silently breaks: router replay and FP8 servers (NeMo-RL code in vLLM).
  4. One shared vLLM-side package instead of hand copies, so the wheel and the managed server can't drift apart (same page).
