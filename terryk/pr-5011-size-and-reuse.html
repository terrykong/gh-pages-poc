Before
Saving and restoring rollouts lived inside the single controller, a 6,688-line class, next to its Gym-only branches.
This PR
Moves that code into two new packages, with the same behavior. The controller drops to 4,714 lines. Source grows by about 850 lines and tests by about 510.
Status
Cuts proposed, not in the PR. The review found no bugs. The cuts below are review asks (C2, C3, C5–C10). Nothing here has been run.

The move itself is careful. Each of the 27 methods that left single_controller.py was compared with its new home, and the differences are renames. The extra lines are not in the moved code. They are in what the move added around it: eight new files, each with its own license, docstring and imports; two Protocol classes with only one real implementation; a 99-line test helper that rebuilds the controller's setup; and a design doc that lists private methods.

What stayed the same

sameLock order around a save, the optimizer-commit window, and restore order (replay → ledger → spare prompts → loader place).
sameOn-disk checkpoint keys (gym_instance_id, gym_attempt) and schema version, so old checkpoints restore.
sameTelemetry keys, including gym_restarted_episodes and the gym_unavailable reason. One log line did change its key (C1).
sameChecks that two commits drop: setup or the Gym adapter already makes each one on the same checkpoint.
sameTests: every removed test moved or went with a duplicate check. 1,233 changed CPU tests pass; the Ray-cluster and triton ones were not run.

The largest source cut: delete the two Protocol classes (C2)

Where the fix lands: RL only, four files. interfaces.py loses both classes; three type hints change. Gym itself needs no change.

Only one real backend exists, GymEnvironmentCheckpoint. The do-nothing backend, NoEnvironmentCheckpoint, does not use the Protocol, and the test stand-ins inherit from it. Nothing checks the Protocol while the program runs, so naming the two real classes keeps behavior the same and adds no is None checks.
