Five pages on this PR. This one: a cleanup the review asks for, and why it is safe.

On turn 2, vLLM hands the worker every image in the prompt: old image A again, plus new image B. Only B should be saved. capture_processed_media already builds one list entry per image, old images first (captured_media.py:260). Today it glues those entries into one tensor and then calls slice_media_tensors, which has to work out again, from totals, where A ends. The simpler way is to drop A's entry before gluing.

Same input, same output, less work
