Five pages on this PR. Page 1 explains what the test proves. This one: how much of the current head the test needs.

The test reads the rows each run trained on from the trainer's own dump (load_training_records), then checks each restored call: it finished once, it starts its row's last call, and its first tokens hash to what the restore logged (_assert_prefix_boundary). Every other row must match the uninterrupted run exactly. Those checks are worth keeping. The extra lines are the same lookups built several times, a jq file with one caller, and unused options.
