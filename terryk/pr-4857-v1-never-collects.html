Two pages on this PR. This one: which workers get the collection.

The flag has two halves. The end of setup turns automatic GC off for every Megatron policy worker (__init__ L1161). The periodic collection runs after an optimizer step, in train() L1571 and finish_train_step L2273. A worker that turns GC off but never trains never collects. A worker that isn't a policy worker never reads the flag at all.

Which workers collect, with manual_gc_interval: 2 over 5 steps

So what. With the flag on, MOPD runs every teacher with no garbage collection, so teacher host memory grows for the whole job. PPO gets the lockstep collect on the policy ranks only, and the value ranks keep stalling each other. Until C2 lands, don't turn the flag on for OPD/MOPD runs.
