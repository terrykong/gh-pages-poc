Background. Each data-parallel shard runs one Ray actor, VllmAsyncGenerationWorker, which owns one vLLM AsyncLLM engine. Every lane below is a different door into that same engine. N is the number of shards. A NeMo RL rollout is the training loop's own token-in, token-out call; a NeMo-Gym call is an OpenAI-style chat request from Gym's environment servers. Dotted words have a short explanation: hover or tap them.

Five ways in, one engine

A and D meet at _serve_rollout, so a NeMo RL rollout is sampled the same way either way. B and C meet at the worker's HTTP server. E, Gym through Dynamo, skips that server: the Dynamo frontend renders the chat template, and NativeVllmEngine redoes on token ids what the server's chat route does on messages. It then calls the same token-capture code.

Short answers

  • What is #4979? The PR stacked on top of #4905. #4905 builds the Dynamo plumbing and uses it only for NeMo RL's own rollouts, so it refuses Gym. #4979 points Gym at the same frontend and teaches NativeVllmEngine to serve Gym's chat calls. The author split it out because it needs a Gym change too. (#4979's own page.)
  • Is the worker's server vLLM's API server? No. It is NeMo RL's FastAPI app, but its chat route runs vLLM's own request classes, extended with mixins.
  • Does the router reuse those servers? Yes. It is a proxy in front of the same N worker URLs.
  • Does Dynamo sit in front of the worker's server? No, in both D and E. Dynamo's Rust frontend is the HTTP server. It reaches NativeVllmEngine inside the worker over its own TCP channel, and the worker's FastAPI server is not on that path.
So what. All five lanes end in the same AsyncLLM, so refit and pause behave the same for every caller. Dynamo changes two things: who picks the shard (cached prompt blocks instead of round-robin or a hash) and how the request gets there (HTTP to the frontend, then TCP, instead of a Ray call or HTTP to the worker). For NeMo RL's own multi-turn rollouts, D is the first lane that aims a later turn at the shard holding its earlier turns; A reuses that cache only when round-robin happens to land there. The extra hop is the cost the #4905 review asks the author to measure.
