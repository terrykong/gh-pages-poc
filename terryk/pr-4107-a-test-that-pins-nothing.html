Three pages on this PR, one question each — this one: why the new test is weaker than it looks.

The point of this PR is that reading a batch out of the small in-process store no longer copies it. The new test proves that by fetching a batch and checking that what comes back is the very object that went in — three is and data_ptr() checks, on a tensor field and on an image field. A check like that only means something if it would have failed on the old code. Two of these three would have passed there too, because of one call on line 99.

What each check can actually tell you

The sharing branch is multimodal_utils.py:611-613 — list(self.tensors) if self.deduplication_enabled. Measured by driving the real put_samples → get_data → materialize_local path at both commits.
