How shared-prefix GRPO in NeMo RL differs from MiniMax Forge and QwenGyre

NVIDIA-NeMo/RL #4537 (draft) at f524ddc9, compared with the Forge blog post and the QwenGyre paper (arXiv 2609.33848). Where a source says nothing on a point, the table says "not described".

Before
NeMo RL computed every completion's prompt again for each completion, in both the log-probability pass and training.
This PR
Computes each GRPO prompt once per forward, with its completions as branches of a one-level tree.
Status
Proposed — draft, off by default. Needs the unmerged Megatron-LM #7914.
how the batch is formed vs Forge and QwenGyre

Two pages on this PR — this one: what each system shares, and where the work is saved.

All three avoid repeated work on text that many training rows have in common. They differ in what they treat as common and where they save the work. This PR shares only the GRPO prompt and saves forward compute. Forge shares multi-turn agent history and also saves forward compute. QwenGyre stores agent runs as trees but trains ordinary rows; it saves by not training the same target tokens twice.

What this PR does not do

  • No multi-turn sharing. Turns after the first are part of the completion, so two branches that share turns 1–3 still compute those turns twice. Forge targets exactly this case.
  • No sharing across bins or ranks. Each forward stores its own copy of a prompt, and the token budget still counts rows at full length.
  • No target selection. GRPO completions don't overlap, so QwenGyre's masking has nothing to remove here.
So what. This PR is the GRPO-shaped special case of Forge's idea: one shared prompt, one level deep, fully specified down to the rank and the attention kernel. Forge's post claims more, but describes too little to compare packing or exactness. QwenGyre solves a different problem: it limits repeated training targets in long agent runs, and still recomputes shared context. Extending this PR to multi-turn agents would need deeper trees, which the layout can describe but the model code rejects today.
